# PythonFirstProg

This repository contains a collection of beginner-level Python programs created as part of an introductory programming course. The projects demonstrate fundamental programming concepts such as control structures, functions, file handling, and basic algorithm design.

## Projects Included

- **Rock, Paper, Scissors Game** – A simple implementation of the classic game.
- **Contact Book** – A basic program to manage contacts using file input/output.
- **Average MPG Calculator** – Calculates average miles per gallon based on user input.
- **Rhyming Words Generator** – A fun program to create rhyming word patterns.
- **Midterm Exam Programs** – Solutions or practice problems from the course midterm.
- **Weather Analyzer** – Reads and interprets weather data.
- **Zeller's Algorithm** – Determines the day of the week for a given date.
- **Net Pay Calculator** – Computes an employee’s net pay after deductions.
- **Pikachu ASCII Art** – Fun and creative use of print statements to draw Pikachu.
- **Pattern Generator** – Generates text-based patterns for console output.
- **GPA Calculator** – Calculates a student's GPA based on input grades.

## Purpose

This repository serves as a showcase of my early programming progress and a reference for others learning Python. Each script is self-contained and runnable from the command line.

## Requirements

- Python 3.x
